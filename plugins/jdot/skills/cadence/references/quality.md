# Quality gate

- Intent: output matches the requested deliverable and constraints.
- Creative: specific imagery, coherent perspective, natural phrasing and original expression.
- Technical: actionable instructions, explicit assumptions, sensible signal flow and objective listening checks.
- Educational: correct concepts, appropriate scaffolding and independent learner participation.
- Evidence: distinguish observed facts, proposed settings and unverified claims.
- Handoff: unresolved blockers and next actions are explicit where relevant.
- Privacy: no persistence of optimization-session details or unauthorized external changes.

If a gate fails, return to Meeko for targeted refinement, then recheck. Report unresolved failures.
