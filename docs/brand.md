# Jdot mark

The page outline represents retained context; the attached dot represents the current item being carried into memory. Three short lines remain recognizable at small sizes without relying on text, animation, remote assets, or gradients.

The light and dark SVGs share identical geometry and use contrasting green palettes on pale and deep backgrounds. The compact square icon uses the same page-and-dot silhouette for composer UI. The manifest points to the light logo and icon; the dark variant is a separate package asset.
